- バージョン: v1.3 (確定。大名家を12家に増やした)
- 作成日: 2026-10-25 / 更新日: 2026-10-25
- ステータス: 要件確定。実装着手可能

---

## 1. 概要

5×6 の小さな盤で遊ぶ将棋のルールを土台に、駒を戦国武将にした、子ども・家族向けの簡単な将棋ゲーム。
大名家を選んで対戦し、1局に1回だけ使える大名ごとの必殺技で盛り上がる。

### 1.1 目的・ターゲット

- 子ども・家族で遊ぶ。ルールを知らなくても駒の印を見ればすぐ遊べること
- 戦国武将が好きな子が「推しの大名で戦える」と感じられること
- まず動くものを短期間で作り、遊びながらバランスを調整する

### 1.2 注意

市販されている既存の将棋ゲームの名称・キャラクター・デザインは使わない。
本ゲームはルールを参考にするが、名称・キャラクター・デザインは使わず、戦国オリジナルの表現にする。

## 2. 対応環境・技術スタック

| 項目 | 内容 |
|---|---|
| プラットフォーム | Webブラウザ (PC・タブレット・スマホ)。タッチ操作を前提に大きめのボタン。スマホは横向き固定 (縦向きでは「よこに してね」を出す) |
| 対戦形式 | 同一端末でのローカル2人対戦のみ |
| 言語 / FW | TypeScript + React + Vite |
| 状態管理 | React 標準 (useReducer)。外部ライブラリなし |
| テスト | Vitest。ゲームエンジン部分はUIと分離して単体テスト |
| 画像素材 | かわいいデフォルメ武将のイラストを SVG で自作 (差し替え可能な構成にする) |
| 効果音 | 短い効果音。Web Audio による合成音またはフリー素材。差し替え可能にする |
| サーバー | 不要。静的ホスティングで配布 |

### 2.1 アーキテクチャ方針

- `engine/` : 盤面・合法手・成り・打ち駒・勝敗判定・必殺技の解決。純粋関数、UI非依存
- `data/` : 大名家・武将・必殺技・駒の定義データ
- `ui/` : React コンポーネント。engine を呼び、アニメーションと効果音を担当
- 必殺技は engine 側で「通常手と同じ state → state の遷移」として扱う

## 3. 画面構成

```
タイトル → 大名選択 (先手 / 後手) → 合戦 → 結果
```

### 3.1 タイトル
- タイトルロゴ、「あそぶ」ボタン
- 12家の大将が横にスライドしていくカルーセル。スワイプや ◀ ▶ でも動かせる
- 大将を押すと、家紋・本拠地・大将・配下の武将 (金・銀)・必殺技を紹介する窓が開く

### 3.2 大名選択
- デフォルメした日本地図の上で、各家の本拠地 (伊達=米沢、島津=薩摩 など) から選ぶ
- 先手を選ぶと、続けて後手を選ぶ番になる。右側のタブやカードで、どちらを選ぶか切り替えられる
- 選んだ家は地図上で大きくなり「先手」「後手」の札がつく。「おまかせ」で ランダムに選べる
- あそびかたを選ぶ: 「かんたん (3×4)」か「じっくり (5×6)」。最初は「かんたん」
- 先手・後手がそれぞれ大名家を選ぶ (同じ家も可)
- 選択中の家の大将・武将・必殺技を絵つきで表示
- 「かいせん (開戦)」ボタン

### 3.3 合戦
- 5×6 の盤。先手が下、後手が上
- 両者の持ち駒 (寝返り武将) 置き場
- 手番表示 (大名家の名前と色)
- 必殺技ボタン (未使用 / 使用済み)
- 駒を選ぶと動けるマスをハイライト
- 駒には動ける方向の印 (点) をつける
- 駒を取ったとき・成ったとき・必殺技のときに簡単なアニメーションと効果音

### 3.4 結果
- 勝った大名家と大将のイラスト、「○○家の勝ち!」
- 「もういっかい」「大名をえらびなおす」

## 4. 基本ルール: じっくり (5×6 の小さな将棋)

### 4.1 盤と駒

- 盤: 5列 × 6段
- 片側 8枚: 大将 ×1、金の武将 ×2、銀の武将 ×2、足軽 ×3

| 本ゲーム | 本将棋で近い駒 | 動き | 成り |
|---|---|---|---|
| 大将 (大名) | 王将 | 全8方向に1マス | なし |
| 金の武将 | 金将 | 前・斜め前・横・後ろ (6方向) に1マス | なし |
| 銀の武将 | 銀将 | 前・斜め前・斜め後ろ (5方向) に1マス | 成ると金の武将と同じ動き |
| 足軽 | 歩兵 | 前に1マス | 成ると金の武将と同じ動き |

### 4.2 初期配置 (足軽は中央で向かい合う)

```
6段目 (後手)  銀 金 大将 金 銀
5段目 (後手)  ・ ・ ・   ・ ・
4段目 (後手)  ・ 足 足   足 ・
3段目 (先手)  ・ 足 足   足 ・
2段目 (先手)  ・ ・ ・   ・ ・
1段目 (先手)  銀 金 大将 金 銀
```

- 足軽が最初から隣接して向かい合うため、初手から駒の取り合いが始まる

### 4.3 成り
- 敵陣は相手側の奥2段 (先手なら5・6段目、後手なら1・2段目)
- 銀の武将と足軽は、敵陣に入ったとき (または敵陣内で動いたとき) に成る (自動。選択なし)
- 成った駒を取ると元の駒に戻る
- 表現: 足軽は「出世」、銀の武将は「武勲」として駒の見た目が変わる

### 4.4 持ち駒と打ち駒 (寝返り)
- 取った駒は持ち駒になる = 「寝返り」。武将名はそのまま、色が自分の家の色になる
- 空いているマスならどこにでも打てる
- 例外: 足軽は相手側の一番奥の段には打てない (動けなくなるため)
- 二歩 (同じ列に足軽2枚) と打ち歩詰めは禁止しない (子ども向けに覚えることを減らすため。本将棋とは違う)

### 4.5 勝敗
- 相手の大将を取ったら勝ち
- トライ (大将が相手の一番奥の段に入る) による勝ちはなし
- 自分の大将が取られる場所に動くこと (自殺手) は禁止しない。そのまま取られたら負け。UIで「大将が危ない!」と注意表示だけ出す
- 千日手: 同一局面が3回現れたら引き分け

## 4B. 基本ルール: かんたん (3×4 の小さな将棋)

1局を短くするためのモード。4章との違いだけを書く。

### 4B.1 盤と駒
- 盤: 3列 × 4段
- 片側 4枚: 大将 ×1、金の武将 ×1、銀の武将 ×1、足軽 ×1

| 本ゲーム | 動き | 成り |
|---|---|---|
| 大将 | 全8方向に1マス | なし |
| 金の武将 | たて・よこ (4方向) に1マス | なし |
| 銀の武将 | ななめ (4方向) に1マス | なし |
| 足軽 | 前に1マス | 相手の一番奥の段に入ると成り、金 (6方向) の動きになる |

- 金の武将と銀の武将には、5×6 の金の武将2人を使う (織田なら 金=柴田勝家、銀=明智光秀)

### 4B.2 初期配置 (先手から見た並び)

```
4段目 (後手)  金 大将 銀
3段目 (後手)  ・ 足   ・
2段目 (先手)  ・ 足   ・
1段目 (先手)  銀 大将 金
```

### 4B.3 勝敗
- 相手の大将を取ったら勝ち
- トライ: 大将が相手の一番奥の段に入り、相手の番のあいだ取られずに残ったら勝ち
- 千日手・打ち駒・自殺手の扱いは 5×6 と同じ

### 4B.4 必殺技の調整
- 鉄砲三段撃ち: 5×6 と同じ (前1〜2マス)。前1マスだけにすると足軽で普通に取るのと変わらないため
- 風林火山: 5×6 と同じ
- 毘沙門天の加護: 技の途中は、相手の一番奥の段に入れない。大将の2回移動で一気にトライできてしまうため

## 5. 戦国要素

### 5.1 大名家 (12家)

2026-10-25 に9家 (豊臣・徳川・毛利・北条・今川・伊達・島津・長宗我部・真田) を追加した。
追加した9家の武将・必殺技・色・家紋・見た目は [families-proposal.md](families-proposal.md) を正とする。下の表は最初の3家。


| 大名家 | 大将 | 金の武将 ×2 | 銀の武将 ×2 | 色 (実装時に調整可) |
|---|---|---|---|---|
| 織田家 | 織田信長 | 柴田勝家 / 明智光秀 | 羽柴秀吉 / 前田利家 | 黒 + 赤 |
| 武田家 | 武田信玄 | 山県昌景 / 馬場信春 | 真田幸隆 / 山本勘助 | 赤 + 金 |
| 上杉家 | 上杉謙信 | 柿崎景家 / 直江兼続 | 宇佐美定満 / 甘粕景持 | 白 + 紺 |

- 足軽は無名。全家共通で「足軽」
- 歴史考証は厳密でなくてよい。子どもにも通じる知名度を優先
- 武将の割り当ては確定 (後から差し替えも可能な構成にする)

### 5.2 必殺技 (1局に1回。大名ごとに個性)

**共通ルール**
- 1局に1回だけ使える。使うと「使用済み」になる
- 自分の手番にだけ使える
- 発動時は技名を大きく表示し、効果音とアニメーションを出す

**技の内容 (確定。強さは実装後に遊びながら調整)**

| 大名家 | 技名 | 効果 | 手番の消費 |
|---|---|---|---|
| 織田家 | 鉄砲三段撃ち | 自分の足軽1枚を選び、その正面1〜2マス以内にいる敵駒1枚を取る (大将は不可)。足軽は動かない。取った駒は持ち駒になる | この技で1手 |
| 武田家 | 風林火山 | この手番、大将以外の駒を続けて2回動かせる。ただし2回目では駒を取れない | 2回の移動で1手 |
| 上杉家 | 毘沙門天の加護 | この手番、大将を続けて2回動かせる。2回目で駒を取ってもよい (相手の大将を取れば勝ち) | 2回の移動で1手 |

> 検討メモ
> - 武田は「家臣の機動力」、上杉は「謙信自身の突撃」と性格が分かれる。上杉の技は2マス先の相手の大将を取れる一方、大将が敵陣に飛び込むリスクもあり、攻守の判断が必要になる
> - 武田の2回移動は大将を対象外にし、2回目で駒を取れないことで抑えている
> - 強さは実装後に遊んで確認し、必要なら調整する
> - 子ども向けなので、技の説明は1行で言い切れる長さに保つ

## 6. UI / ビジュアル

### 6.1 方向性
- かわいいデフォルメ武将。丸いイラストと明るい色
- 大名家ごとに駒の色を変える (5.1 参照)
- 駒には動ける方向の印 (小さな点や矢印) をつける。成ると印が増える
- 後手の駒は上下反転ではなく、向きが分かる印と色で区別 (実装時に見比べて決める)

### 6.2 操作
- タップ (クリック) で駒を選ぶ → 動けるマスが光る → タップで動く
- 持ち駒をタップ → 打てるマスが光る → タップで打つ
- 必殺技ボタン → 対象を選ぶモード → 対象をタップで発動。キャンセル可
- 誤操作を防ぐため、駒とボタンは指で押しやすい大きさ (44px 以上)

### 6.3 演出
- 駒を取る: 取られた駒が持ち駒置き場へ飛んでいく + 「寝返り!」の短い表示と効果音
- 成り: 駒が光って絵が変わる + 効果音
- 必殺技: 技名を大きく表示 + 効果音
- 勝利: 大将のイラストと「○○家の勝ち!」+ ファンファーレ

### 6.4 今回は入れないもの
- オンライン対戦
- 待った、棋譜、持ち時間
- ルール説明画面 (駒の印で代替)

## 7. 開発ステップ案

1. **エンジン**: 5×6 のルールを `engine/` に実装し、Vitest でテスト (動き・成り・打ち駒・足軽の最奥段禁止・勝敗)
2. **最小UI**: 文字だけの盤で2人対戦が成立する状態にする
3. **大名・武将データ**: 3家分の名前・色を駒に反映。大名選択画面を追加
4. **必殺技**: 3家の技をエンジンに実装 + 発動UI
5. **イラスト**: デフォルメ武将の SVG を作成し、駒の見た目と方向の印を実装
6. **演出**: 効果音とアニメーション、タイトル・結果画面
7. **バランス調整**: 家族で遊んで必殺技の強さを調整
