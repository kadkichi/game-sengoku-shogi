# 大坂冬の陣・夏の陣モード

- 作成日: 2026-10-27
- ステータス: 採用・実装済み (2026-10-27)

## 1. 基本

- 盤は じっくり (5×6) だけ。トライはない
- 徳川方か豊臣方かを選ぶ。冬と夏で 顔ぶれは同じで、必殺技だけ違う
- 足軽の代わりに 名前のある「先鋒」(前・左・右) を置く (関ヶ原と同じ)

## 2. 顔ぶれ

| 位置 | 徳川方 | 豊臣方 |
|---|---|---|
| 大将 | 徳川家康 | 豊臣秀頼 |
| 金の武将 | 徳川秀忠 / 井伊直孝 | 真田幸村 / 後藤又兵衛 |
| 銀の武将 | 伊達政宗 / 前田利常 | 木村重成 / 毛利勝永 |
| 先鋒 ×3 | 藤堂高虎 / 松平忠直 / 上杉景勝 | 長宗我部盛親 / 明石全登 / 大野治長 |

## 3. 必殺技 (1局に1回)

| 合戦 | 軍 | 技 | 効果 |
|---|---|---|---|
| 冬の陣 | 豊臣方 | 真田丸 | 真田幸村と まわり8マスの味方は、次の相手の番 取られない。手番を使わず、そのあと ふつうに指す。幸村が取られたら使えない |
| 冬の陣 | 徳川方 | 大筒の砲撃 | 相手の陣 (奥2段) にいる駒を1枚、どこからでも取る。大将は取れない |
| 夏の陣 | 豊臣方 | 日本一の兵 | 真田幸村が まっすぐ前か ななめ前に 何マスでも進む。止まった先の敵は取れる。幸村が取られたら使えない |
| 夏の陣 | 徳川方 | 大軍の進軍 | 大将以外の駒を3枚まで、1マスずつ前に進める (取れない)。毛利家の三本の矢と同じ仕組み |

## 4. 盤の柄 (見た目だけ。ルールは変わらない)

- 豊臣方の陣 (奥2段) に、大坂城のイラストを置く。長い石垣の上に、緑青の屋根・白壁・金のしゃちほこの天守と、両端の櫓
  - 奥の段は駒で隠れるので、城は 野原の側の段 (はじめは駒のいない段) に収まるように描く
- 徳川方の陣は 陣地の土の色。あいだは野原
- 冬の陣: 屋根と石垣に雪。野原にも雪。枠は黒っぽい石の色
- 夏の陣: 石垣は くすんだ色。野原は夏草の濃い緑。枠は木の色
- 堀は描かない (2026-10-27 に はずした)
- 豊臣方を先手にしたときは、城は盤の下側にくる
