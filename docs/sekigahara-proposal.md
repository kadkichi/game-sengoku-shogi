# 関ヶ原の合戦モード

- 作成日: 2026-10-27
- ステータス: 採用・実装済み (2026-10-27)

## 1. 基本

- 盤は じっくり (5×6) だけ。トライはない (大将を取ったら勝ち)
- 家ではなく、東軍か西軍かを選ぶ
- 足軽はいない。駒は すべて名前のある武将
- 駒の色は軍ごと (東軍=徳川の深緑、西軍=石田方の紫 など)

## 2. 駒の顔ぶれ (各軍8人)

並びは じっくりの 初期配置と同じ。足軽の3マスに「先鋒」を置く。

| 位置 | 東軍 | 西軍 |
|---|---|---|
| 大将 | 徳川家康 | 石田三成 |
| 金の武将 | 本多忠勝 / 井伊直政 | 島津義弘 / 大谷吉継 |
| 銀の武将 (一番後ろの段の両端) | 福島正則 / 黒田長政 | 小早川秀秋 / 吉川広家 |
| 先鋒 ×3 | 藤堂高虎 / 細川忠興 / 加藤嘉明 | 宇喜多秀家 / 小西行長 / 島左近 |

- 小早川と吉川は 後ろの両端に置く。史実でも 小早川は松尾山、吉川は南宮山と、本隊から離れた位置にいた

### 新しい駒「先鋒」

- 前・左・右の3方向に1マス うごける (足軽より強く、金・銀より弱い)
- 相手の陣 (奥2段) に入ると出世して、金と同じうごきになる

## 3. 必殺技 (1局に1回)

### 東軍「内応の密書」

- 2026-10-27 に変更: 条件なしで使える
- 効果: 盤の上にいる 西軍の小早川秀秋か吉川広家を 1人えらんで、その場で東軍に寝返らせる
  - 2人とも盤上にいれば、どちらかを選ぶ。えらぶ前なら やめられる
  - 持ち駒や、もう東軍になっている駒は 対象外
  - 出世していれば、出世したまま東軍になる
  - 技を使った手番は そこで終わる

### 西軍「島津の退き口」

- 島津義弘が、まっすぐ前に何マスでも進む (真田家の六文銭と同じ仕組み。後ろには進めない)
- 途中の駒は とびこえない。止まったマスの敵は取れる (大将なら勝ち)
- 島津義弘が取られたら使えない。東軍が取って打ち直した島津でも使えない
- 技を使った手番は そこで終わる

## 4. あると楽しい演出 (あとから足してもよい)

- 寝返りのとき、旗の色が変わって「裏切りじゃ!」と出る
- 結果画面を「天下分け目の戦い、東軍の勝ち!」のような言葉にする
- 開戦の朝霧: 最初の数手は相手の駒の名前が見えない

## 5. 作るときの注意

### 実装のしくみ (大坂の陣などを足すとき)

- 東軍・西軍は、大名家と同じ形のデータ (src/data/families.ts の east / west) で持つ。先鋒3人は vanguard、大将の絵は look で決める
- 合戦は src/data/battles.ts に1つずつ定義する。大坂の陣を足すときは、families.ts に軍を2つ、battles.ts に合戦を1つ足し、PLAY_MENU の「じゅんび中」の行に合戦を結びつければ、タイトルの選択の窓・軍の選択画面・結果画面に出る
- 必殺技の charge (決まった1人がまっすぐ前に進む) と naiou (寝返り) は、名前を data で指定するので、ほかの合戦でも使える
- 寝返り演出の「旗の色が変わる」は、駒の色が東軍の色に変わり、光って「内応じゃ!」と出る形にした
- 開戦の朝霧は まだ入れていない

- 新しい武将の絵は十数人ぶん。最初は 東軍・西軍の色で いまの絵を使い回す
- 先鋒は新しい種類の駒なので、ルール・CPU・あそびかた画面・印刷用PDFにも追加が必要
