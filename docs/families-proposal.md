- 作成日: 2026-10-25

## 3. 決定事項と残っている課題

### 3.1 既存の家との重なり (決定)
- 織田家の銀の武将「羽柴秀吉」と豊臣家の豊臣秀吉は、両方そのまま残す
- 武田家の銀の武将「真田幸隆」と真田家も、両方そのまま残す

### 3.2 色 (課題)
次の組み合わせは色が近い。駒の色に加えて、家紋と大将の見た目で見分ける。
- 織田 (黒+赤) と 伊達 (黒+金)
- 武田 (赤+金) と 真田 (赤+黒)
- 徳川 (深緑) と 長宗我部 (黄緑)

### 3.3 大名選択画面 (実装済み)
12家を 4×3 のカードから選ぶ形に作り直した。「おまかせ」でランダムに選べる。

### 3.4 実装で決めた細かいルール
- 一夜城: もちごまが2まい以上あるときだけ使える。1まい打ったあと「1まいで おわる」で終えてもよい
- 鳴くまで待とう: 相手の直前の手番を、その手番の始まりまで戻す。相手がその手番で使った必殺技も 使っていないことに戻る。指し直しでは、取り消された手と同じ最初の一手は指せない。ゲームの1手目 (戻す手がないとき) は使えない
- 三本の矢: 動かせるのは まっすぐ前の空いたマスだけ。駒の動きの点とは関係ない。1まい動かしたあと「ここで おわる」で終えてもよい
- 小田原城: 使った手番は そのまま ふつうに指す。守りは、次の相手の番が終わるまで続く。必殺技 (鉄砲・独眼竜など) でも 取られない
- 独眼竜・六文銭: 敵の大将で止まれば 取れる (勝ち)
- 釣り野伏せ: 引き寄せた駒は 成らない
- 一領具足: 新しい足軽は 長宗我部家の足軽として盤に出る (持ち駒からは減らない)
- 伊達家の家紋は、竹に雀を簡略化するのが難しいため、伊達家の替紋「九曜」にした

### 3.5 強さ (課題)
徳川「鳴くまで待とう」と北条「小田原城」は、子どもには効果がわかりにくい可能性がある。どれも実際に遊んでから調整する。
